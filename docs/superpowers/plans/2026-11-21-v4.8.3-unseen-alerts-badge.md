# V4.8.3 Unseen-only Alerts badge + B2 notice removed — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The bottom-bar Alerts badge counts only notices the person has not seen (any new or changed notice counts again), opening Alerts marks them seen, new rows carry a NEW tag for that visit, and the expired B2 works notice is removed.

**Architecture:** One pure function decides everything (`annSeenStep`), in a new source file `transit_data/src/14b-ann-seen.js` inside a `/* ==ANNSEEN-PURE-START== */ … END` block so tests load it with `vm` like the other pure blocks. `renderAnnouncements()` in `17-boot.js` feeds it the live notices, the stored seen list and whether the card is open, then writes the badge, the NEW tags and `localStorage['irn_ann_seen']`.

**Tech Stack:** plain browser JS concatenated by `transit_data/build.cjs` (files in name order), Node `node:test` suites in `transit_data/test/`, mutation checks in `transit_data/testkit/verify-suite.cjs`.

**Spec:** `docs/superpowers/specs/2026-11-21-unseen-alerts-badge-design.md`

## Global Constraints
- Branch `v4-8-3` from live `main`; PR to main; never push to main; no "merge when green" label until the owner says "merge once green".
- Edit `transit_data/src/*.js`, `transit_data/app.template.html`, `transit_data/legal-*.{json,cjs}`; never hand-edit `index.html` or `legal/*.html` (they are built: `npm run build`).
- Nothing about what a person has read leaves the device; the only storage is `localStorage['irn_ann_seen']` (array of strings), listed on the storage page.
- Count individual notices (rail, ferry, each bus notice), never bus groups; "opening soon" lines are not counted.
- Storage unavailable (throws, private mode) → the badge counts everything, as today.
- Fingerprints use the notice's stored fields only, never translated display text (the language switch must not make notices "new").
- `appVersion` becomes `V4.8.3` in `transit_data/legal-config.json`.
- Before the PR: `npm run verify` green, plus the scratchpad `stale-scan.cjs` and `expect-scan.cjs`.

## Review Focus
1. Wide screen: the `#announce` card can be collapsed (`.collapsed`); a collapsed card is not "open", so nothing is marked seen until it is expanded.
2. Notices that change while the card is open must be marked seen and get the NEW tag in that visit, not leave a badge behind when the card closes.
3. Switching language re-renders everything; no notice may become unseen because of it.
4. A notice that disappears and comes back with the same text (an İETT flicker): pruning keeps only live fingerprints, so it counts again. That follows the owner's "technically new" rule and is pinned by a test, so it is a decision, not an accident.
5. Corrupt `irn_ann_seen` (not JSON, not an array, non-strings) → treated as empty, never a crash.

### Task 1: The pure decision (fingerprint + seen step)

**Files:**
- Create: `transit_data/src/14b-ann-seen.js` (pure block only in this task)
- Test: `transit_data/test/v483.test.cjs`

**Interfaces:**
- Consumes: `_hash(s: string) -> string` from the `NOTICES-PURE` block of `14a-surface-notices.js`.
- Produces:
  - `annFingerprint(d: Notice) -> string` = `d.id + '#' + _hash(JSON.stringify([d.message, d.messageTr, d.severity, d.until, d.from, d.to, d.stations, d.tpl]))` (missing fields serialise as null; nothing else of `d` is read).
  - `annSeenStep(live: Notice[], seen: string[] | null, cardOpen: boolean) -> { seen: string[] | null, fresh: string[], badge: number }`
    - `fresh` = fingerprints of `live` not in `seen` (order of `live`, no duplicates).
    - `cardOpen` → `seen` = all live fingerprints, `badge` = 0.
    - not open → `seen` = previous seen ∩ live fingerprints (pruned), `badge` = `fresh.length`.
    - `seen === null` (storage unavailable) → `{ seen: null, fresh: all live fingerprints, badge: cardOpen ? 0 : live.length }`.
  - `annParseSeen(raw: string | null) -> string[]`: JSON array of strings, anything else → `[]`.

  - `v4.8.3: the badge counts only notices not seen yet` — live A,B,C; seen [fp(A)]; closed → badge 2, fresh [fp(B),fp(C)].
