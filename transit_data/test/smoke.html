Boots the real built page in an iframe and exercises it. This is the tier the static suite cannot reach: a runtime throw, a dead boot, a map that never renders.

    Open this in a normal, visible window. Several checks depend on the page actually painting — requestAnimationFrame does not fire in a background tab, so the animated stat counters would read 0 and the map would report no size. Those checks skip rather than fail when the document is hidden.
